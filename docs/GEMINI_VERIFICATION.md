## Live-test boundary

**No user service account or live Gemini request was used during development.** Configured-Gemini browser cases and provider contract tests use explicit test fixtures or injected test transports. These fixtures are isolated to tests; the application does not contain a production mock-model mode. Screenshots named `gemini-*-fixture-*.png` illustrate the tested UI with those fixtures.

The implementation compiles against the pinned official Google Gen AI SDK and uses its real server-side Vertex AI authentication and generation path. Actual IAM permissions, billing, project/model access, cloud quotas, latency, and live answer quality still require the user's service account. Use **Test connection**, then evaluate actual research questions after configuring it. A successful local test suite is not a claim that those cloud conditions have already been verified.

Evidence and numeric-placeholder validation constrain references and displayed numbers. They do not independently establish that a model's qualitative explanation, causal inference, or selected evidence is correct. Review live responses for analytical depth, valid interpretation, balanced counterarguments, and useful research steps.

## Reproducible checks

From the project root, run `npm run test:ai` and `npm run test:analysis`. From `packages/web`, run `npm run typecheck`, `npm run lint`, `npm run demo:build`, and `npm run test:local` after installing the Playwright browser. The shipped browser fixtures are generated by the AI contract test from active server facts.

Machine-readable results are included in `docs/qa/gemini-unit-verification.json`, `docs/qa/gemini-browser-regression.json`, `docs/qa/gemini-browser-final.json`, and `docs/qa/gemini-model-integrity.json`. The full regression was run after the cancellation fix; the final focused rerun covers the later compact mobile connection view and abort wrapper.
